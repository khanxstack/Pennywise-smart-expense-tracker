# Pennywise — Smart Expense Tracker

A lightweight personal expense tracker built with HTML, CSS, and vanilla JavaScript. No installation, build step, or account is required.

## Run

Open `index.html` in a modern browser. Your expenses and monthly budgets are saved in that browser's local storage.

## Features

- Add expenses with a description, amount, category, and date.
- Review monthly spending, transaction count, and budget remaining.
- See a category breakdown for the selected month.
- Set a separate budget for each month.
- Browse previous months and delete transactions.
- Responsive layout for desktop and mobile screens.

## Files

- `index.html` — tracker layout and forms
- `style.css` — responsive visual design
- `script.js` — expense management, summaries, and local storage
